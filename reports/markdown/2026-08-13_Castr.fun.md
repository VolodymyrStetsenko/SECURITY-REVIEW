## Audit Summary

Castr.fun engaged Kann Audits to review its bonding-curve token launch protocol. From April 4
to April 26, 2026, the security research team manually reviewed the in-scope source code and
triaged findings generated by the Kann Labs Security Model. The final report was published on
August 13, 2026.

## Protocol Overview

Castr.fun is an on-chain token launchpad on Base. It uses Bancor-style bonding curves for
initial price discovery and graduates funded tokens into locked Aerodrome Slipstream
concentrated-liquidity pools. The protocol also includes anti-sniping, vesting, fee,
dividend, reward, and liquidity migration mechanisms.

## Methodology

The engagement combined independent review by security researchers with collaborative
review sessions. The team performed manual line-by-line inspection and analyzed protocol
architecture, access control, state transitions, contract interactions, implementation
assumptions, common and uncommon attack vectors, and conformance with smart contract
security practices. Findings generated by the Kann Labs Security Model were also triaged.
